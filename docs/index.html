安卓端侧离线大模型聊天

HNN CN ET

在安卓手机上本地运行大模型聊天。不用联网、不用付费、聊天记录不上传，32 位老设备也能正常用。

立即下载 APK 查看源码
架构 armeabi-v7a + arm64-v8a 推理引擎 MNN 协议 MIT 版本 v1.3.0

功能特性

端侧离线

模型在手机本地运行，断网也能聊，不用等云端。

隐私本地

聊天记录默认不上传服务器，数据留在自己的设备里。

32 位兼容

同时支持 arm64-v8a 与 armeabi-v7a，老设备也能装。

多模型切换

应用内下载与管理多种模型，按需更换，随时切换。

深度思考

可开启深度思考模式，先分析再回答；关闭则直接回答。

Agent 助手

可打开应用、发消息、看视频、听音乐、创建文件，支持无障碍与悬浮窗。

使用说明（一步步教到能用）

通用三步

  1. 在菜单「1 首页」选择一个已经下载好的模型，启动 API 服务；
  2. 复制屏幕（或手机服务面板）上的 API 地址、密钥、模型名称；
  3. 填到第三方 AI 客户端（Chatbox / NextChat / LobeChat 等）即可对话。
服务端默认绑定 0.0.0.0，同一 Wi-Fi 下其他设备用屏幕显示的「局域网 IP」访问，不要用 127.0.0.1。菜单编号：1 首页 ｜ 2 市场 ｜ 3 远程模式 ｜ 4 更改端口 ｜ 7 密钥开关 ｜ 8 强制密钥 ｜ 0 退出。

📱 一、Termux 手机安装（pkg / apt 双链路）

1. 添加 ETC 软件源（只需一次）

echo "deb https://etqwfd.github.io/HNN-CN-ET/termux stable main" >> $PREFIX/etc/apt/sources.list.d/hnn.list
pkg update

2. 安装（pkg 与 apt 等价，底层同一个源）

pkg install ai        # 等价：apt update && apt install ai

64 位与 32 位包由源自动匹配；若 32 位老手机自动识别失败，可下载 install-termux.sh，脚本先装 32 位 arm，跑不起来再自动回退 64 位 aarch64。

3. 启动并选模型

ai
# 进入后输入 1 回车 → 选择模型编号/名称 → 服务常驻运行

更新：pkg update && pkg upgrade ai；卸载：pkg remove ai。模型目录 ~/.hnn/models。

🐧 二、Linux（Debian / Ubuntu / Kali 等）安装

# 1. 添加源（需 root）
echo "deb [trusted=yes] https://etqwfd.github.io/HNN-CN-ET/linux-repo stable main" | sudo tee /etc/apt/sources.list.d/hnn.list
sudo apt update

# 2. 安装
sudo apt install ai

# 3. 启动
ai

更新：sudo apt update && sudo apt upgrade ai；卸载：sudo apt remove ai。也可直接下载 Linux 便携包，解压后 chmod +x ai llm_demo && ./ai。

🪟 三、Windows 电脑便携包

  1. 下载 Windows 便携包 并解压；
  2. 确保 ai.exe、hnn_core.dll、llm_demo.exe 在同一个文件夹（不要分开移动）；
  3. 双击 run.bat（或运行 ai.exe），按菜单 1 选模型启动服务；
  4. 屏幕会显示本机地址、局域网地址、密钥与模型名，复制到客户端即可。

本版为纯 C 命令行服务端，不再依赖 Qt；程序与 DLL 版权署名均为 ETC，压缩包 source/ 目录内含全部 C 源码（MIT）。

📲 四、Android 手机服务版（APK 内服务面板）

  1. 打开已下载模型，进入 API 服务面板；
  2. 面板顶部三步引导：选模型 → 复制地址/密钥/模型名 → 填到第三方客户端；
  3. 地址、模型名、密钥三项均有一键复制按钮，复制后弹出提示；
  4. 密钥开关说明：关闭密钥时本机与局域网可直接调用；开启强制密钥后，本机和局域网都必须携带正确密钥。

局域网其他设备用手机 Wi-Fi 的局域网 IP 访问；外网访问请自行使用 frpc 等内网穿透工具，服务端不内置穿透。

🔌 五、第三方 AI 客户端接入（Chatbox / NextChat / LobeChat）

客户端设置项填写内容
API 类型 / ProviderOpenAI 兼容（OpenAI Compatible）
Base URL / API 地址http://手机或电脑局域网IP:端口/v1（注意结尾 /v1）
API Key / 密钥屏幕显示的完整 etc-... 密钥（Android 面板按面板显示的密钥填写）
模型名称面板或 GET /v1/models 返回的名称；填完整 ID、目录名、小写变体、归一化名、llm.mnn 均可命中同一模型

最简成功示例（命令行）

curl http://192.168.1.23:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer etc-你的密钥" \
  -d '{"model":"MNN__Qwen2.5-0.5B-Instruct-MNN","messages":[{"role":"user","content":"你好，介绍一下你自己"}]}'

先访问 http://IP:端口/v1/models 可确认当前可用模型列表；浏览器跨域调用已开放 CORS（Access-Control-Allow-Origin: *）。

✍️ 六、自定义系统提示词 system.ini

需要固定人设、回答规则或语气时，在服务端程序当前工作目录新建 system.ini（Android 服务版读取公共模型根目录 /storage/emulated/0/hnn/system.ini，缺失时回退应用私有目录）：

system="你是一个简洁的中文助手，每次回答先给结论，再补充说明。"
  • 支持 system = "..." 空格写法，兼容中文引号 “...”；
  • 文件修改后下一次对话自动生效，无需重启服务；
  • 文件不存在或为空时，保持原有默认行为，不影响正常请求；
  • 远程转发模式（菜单 3）不本地注入，避免与上游系统提示重复。

📱 Termux 一键安装（pkg install ai，32/64 位，纯 C 编译非 Python）

首次先添加 ETC 软件源，之后直接 pkg install ai 按包名安装（64 位与 32 位自动匹配，无需手动下载 deb）：

# 1. 添加 ETC 自建软件源（只需执行一次）
echo "deb https://etqwfd.github.io/HNN-CN-ET/termux stable main" >> $PREFIX/etc/apt/sources.list.d/hnn.list
pkg update

# 2. 直接安装（aarch64 / arm 32 位自动识别）
pkg install ai          # 等价 apt install ai

# 3. 启动服务端
ai

更新版本：pkg update && pkg upgrade ai；卸载：pkg remove ai。
菜单：1 首页（递归列出已下载模型，名称/编号/llm.mnn 均可加载）｜2 市场（ModelScope 官方 API 下载，与手机版一致）｜3 远程模式｜4 更改端口｜7 密钥开关｜8 强制密钥｜0 退出。
自定义人设：在当前目录 system.ini 写 system="提示语"，下次对话生效。纯 C 编译（二进制 ~30KB），内存占用极小，模型存 ~/.hnn/models；安装包内含全部源码。离线兜底脚本先尝试 32 位 arm，无法启动再回退 64 位 aarch64。

兜底方式（源不可用时手动安装）：64 位 ai-termux-arm64.deb，32 位 ai-termux-arm.deb，下载后 pkg install ./文件名.deb；也可使用 install-termux.sh 自动先 32 位探测、失败回退 64 位。

🐧 Linux（Debian / Ubuntu / Kali 等）一键安装（apt install ai）

# 1. 添加 ETC 软件源（只需执行一次，需 root）
echo "deb [trusted=yes] https://etqwfd.github.io/HNN-CN-ET/linux-repo stable main" | sudo tee /etc/apt/sources.list.d/hnn.list
sudo apt update

# 2. 直接安装
sudo apt install ai

# 3. 启动服务端
ai

更新：sudo apt update && sudo apt upgrade ai；卸载：sudo apt remove ai。模型目录 ~/.hnn/models，菜单与 Termux 版一致。
