安卓端侧离线大模型聊天

HNN CN ET

在安卓手机上本地运行大模型聊天。不用联网、不用付费、聊天记录不上传，32 位老设备也能正常用。

立即下载 APK 查看源码
架构 armeabi-v7a + arm64-v8a 推理引擎 MNN 协议 MIT 版本 v1.2.2

功能特性

端侧离线

模型在手机本地运行，断网也能聊，不用等云端。

隐私本地

聊天记录默认不上传服务器，数据留在自己的设备里。

32 位兼容

同时支持 arm64-v8a 与 armeabi-v7a，老设备也能装。

多模型切换

应用内下载与管理多种模型，按需更换，随时切换。

深度思考

可开启深度思考模式，先分析再回答；关闭则直接回答。

Agent 助手

可打开应用、发消息、看视频、听音乐、创建文件，支持无障碍与悬浮窗。

使用说明

1

下载 APK 并安装到安卓手机。

2

首次打开，按提示下载一个模型。

3

选好模型进入聊天，等待初始化完成后即可对话。

4

需要联网功能时，在设置里开启 API 服务或 Agent 模式。
