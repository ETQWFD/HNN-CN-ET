HNN CN ET

纯 C 命令行模型服务端。基于 MNN 做本地推理，提供 OpenAI 兼容接口，支持 Termux、Linux、Windows。模型经 ModelScope 官方通道下载，解压即可运行。

安装

Termux（手机，pkg / apt 通用）

# 1. 添加源（只需一次）
echo "deb [trusted=yes] https://etqwfd.github.io/HNN-CN-ET/termux stable main" >> $PREFIX/etc/apt/sources.list.d/hnn.list
pkg update

# 2. 安装（32/64 位由源自动匹配）
pkg install ai

# 3. 启动
ai

更新 pkg upgrade ai，卸载 pkg remove ai。32 位老手机若识别失败，运行 install-termux.sh 自动回退。模型目录 ~/.hnn/models。

Linux（Debian / Ubuntu / Kali）

echo "deb [trusted=yes] https://etqwfd.github.io/HNN-CN-ET/linux-repo stable main" | sudo tee /etc/apt/sources.list.d/hnn.list
sudo apt update
sudo apt install ai
ai

不便用 root 时下载 Linux 便携 zip，解压后 chmod +x ai llm_demo && ./ai。

Windows

  1. 下载 HNN-CN-ET-Server-Windows.zip 并解压，保持文件在同一文件夹；
  2. 双击 run.bat 或运行 ai.exe；
  3. 三个程序均为全静态编译，仅依赖 Windows 10 及以上系统自带的 UCRT，无任何第三方 DLL，解压即用。

快速开始

  1. 菜单输入 1，选择一个已下载的模型，启动服务；
  2. 屏幕显示 API 地址、密钥、模型名，复制；
  3. 填到第三方客户端的 Base URL / API Key / 模型名即可对话。

菜单编号：1 首页选模型 ｜ 2 模型市场下载 ｜ 3 远程转发 ｜ 4 改端口 ｜ 7 密钥开关 ｜ 8 强制密钥 ｜ 0 退出。

服务默认绑定 0.0.0.0，同一 Wi-Fi 下用屏幕显示的局域网 IP 访问，不要用 127.0.0.1。外网访问自行配置 frpc 等穿透。

API 调用

接口为 OpenAI 兼容，鉴权开启时带 Authorization: Bearer etc-...。

# 模型列表
curl http://192.168.1.23:8080/v1/models \
  -H "Authorization: Bearer etc-你的密钥"

# 对话
curl http://192.168.1.23:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer etc-你的密钥" \
  -d '{"model":"Qwen2.5-0.5B-Instruct-MNN","messages":[{"role":"user","content":"你好"}]}'
客户端设置项填写内容
接口类型OpenAI 兼容
Base URLhttp://局域网IP:端口/v1
API Key完整 etc-... 密钥
模型名完整 ID、目录名、大小写变体、归一化名均可命中，无需固定输 llm.mnn

已开放 CORS，浏览器可直接跨域调用。

system.ini 自定义提示词

在程序当前工作目录新建 system.ini，写入：

system="你是一个简洁的中文助手，先给结论，再补充说明。"
  • 兼容 system = "..." 空格写法与中文引号；
  • 修改后下一次对话自动生效，无需重启；
  • 文件缺失或为空时保持默认行为。

错误对照

现象原因处理
缺 libgcc_s_seh / libwinpthread / libc++.dll运行的是旧包删除旧解压目录，重新下载 v1.3.4 全静态包（已无第三方 DLL）
no Qt platform plugin旧 Qt 桌面版改用 v1.3.4 纯 C 命令行版，不依赖 Qt
TLS initialization failed网络/代理握手失败换网络或关代理，确认能打开 ModelScope 后重试
Failed to fetch repo info仓库索引拉取失败检查网络后重试，先选小模型验证
下载后首页不显示嵌套目录未扫描v1.3.4 已递归扫描；确认目录含 config.json 且位于 ~/.hnn/models
老手机加载即闪退内存不足关闭后台应用，选 32 位包与小参数模型
401 bearer 错误密钥缺失或不完整重新复制完整 etc-...；菜单 7/8 可调整鉴权
端口绑定失败端口被占用菜单 4 改端口后重启
局域网设备连不上网络/防火墙/误用 127.0.0.1同一 Wi-Fi、放行防火墙、用局域网 IP
必须输 llm.mnn旧版解析缺陷升级 v1.3.4，真实模型名可直接命中
