功能特性

为真实可用而做，不是 Demo。

端侧离线聊天

基于阿里 MNN 推理引擎，模型在本地运行，聊天记录不上传任何服务器。

真实 32 位支持

APK 内同时打包 armeabi-v7a（32 位）与 arm64-v8a（64 位）原生库，老设备、新设备都能安装运行。

应用内自动更新

启动时检查 GitHub Release，发现新版展示更新内容，APK 支持断点续传与失败重试，下完直接调起系统安装器。

完整日志页

记录启动、模型下载、推理加载、更新与错误堆栈，支持一键复制、按级别筛选，方便定位问题。

模型下载器

内置模型下载与进度/速度显示，支持断点续传与文件校验；下载完成后可直接加载对话。

联系作者

设置页内置「联系作者」入口，一键唤起邮箱；也可加入 QQ 群反馈问题。

使用说明

三步开始离线聊天。

1

安装 APK

从上方下载最新 APK，点击安装。首次安装时系统会提示「未知来源」，允许本应用安装即可（Android 8+ 需要在设置里授权）。

2

下载模型

首次打开会引导下载模型（GGUF/MNN 格式）。建议在 Wi-Fi 环境下下载，进度与速度会实时显示，支持断点续传。

3

开始聊天

模型加载完成后即可在主界面对话。之后再次启动无需重新下载，离线可用。如遇问题可在「日志」页复制日志反馈。
